# Student Marks Calculator

This is a simple Python project for calculating the total marks of a student.

## Features
- Takes student name as input
- Takes marks in English, Maths, and Python
- Calculates the total marks
- Displays the student's details

## Technologies Used
- Python

## How It Works
The program asks the user to enter the student's name and marks in three subjects.
It then calculates and displays the total marks.
